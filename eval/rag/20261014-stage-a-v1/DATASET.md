# RAG Stage A 合成开发评测 v1

72条查询：精确关键词12、同义/口语12、简称/概念替换8、历史指代8、相似文档干扰8、跨段落8、无答案16。保留原8篇校园资料，另加8篇MIT原创合成资料，仅导入隔离评测库。

每条标注明确的document_id及唯一原文quote；prepare按原文坐标绑定chunk/source ID，不读取排名。多段问题标注多个证据组；重叠切块均可作为同组替代来源。标准chunk Recall使用所有可接受chunk的集合；文档Recall与证据组覆盖率另报，避免将多证据查询混作单证据命中率。

无答案分为域外、未提供事实和无当前校园资料。未提供事实即用户请求的数字、时间、资格或保证无法由资料直接回答；检索到同主题提示仍视为检索层未拒绝，不等同于最终回复会编造答案。拒答指标在Stage A是空检索判定，没有调用Response/Reviewer模型。

标签由开发过程人工编写的规则和证据明确化，未经过独立标注者裁决。此版本用于诊断检索短板，不能作为后续优化后独立测试集。查询和资料冻结后运行基线，后续沿用同一版本比较。

历史组保留现有ContextAgent规则，包括不触发历史扩展的“之前/继续”案例。Intent固定为校园知识需求，Risk固定为LOW，以隔离检索、历史扩展和仲裁质量；不计模型意图/风险准确率。
