# 简历与作品集

## 项目介绍

**CampusBridge · 校园学生支持多Agent系统**

独立设计并实现学生对话与辅导员跟进Web应用，使用Python/FastAPI/Pydantic/SQLAlchemy/SQLite与React/TypeScript，构建动态任务图、并行意图/风险分析、结果仲裁、可追溯RAG引用、最终回复审核和人工工单闭环，提供冻结真实模型评测与跨平台自动化检查。

## 三条技术成果

1. **动态多Agent编排：**设计类型化Task/Dependency/ExecutionPlan与确定性Arbitrator，独立Intent/Risk并发，按需选择Context/RAG并控制预算/超时/取消；真实对照中Agent任务执行176→150、P50 4.32s→3.43s，固定集保持28/30。
2. **可靠交付与人工闭环：**实现完整候选生成后审核、candidate/content/citation Hash绑定、有限重生成和审核后SSE；风险事项独立事务提交，辅导员工单支持认领/处理/关闭、版本检查、权限与幂等审计，生成故障时事项保留。
3. **引用治理与评测：**实现版本化SQLite FTS5/BM25检索、本轮引用白名单及无效证据仲裁，固定原创30+12条用例和逐条Trace/Hash；真实边界成功10/12→12/12、兜底2→0，模型请求125→126透明列出；发布回归覆盖后端、前端和干净安装。

## 面试展开

优先讲一个具体链路：用户请求如何生成计划、何时并行、仲裁怎样定路由、风险事项何时落库、回复如何通过审核才交付。随后展示真实Trace中的任务区间与候选Hash，再说明一条边界失败怎样被证据/来源校验解决。

技术取舍：轻量任务调度复用现有角色；单进程短事务保证业务一致性；并发子任务只返回独立结果，协调器合并；知识检索先用可调试词面索引；模型协议、工程行为和人工业务分别评测。
