## 解释

两条 cb2-r03/r04 的原 gold 为 MODERATE；当前策略输出 LOW + needs_human_support=true，仍创建工单，按旧标签计为 risk 失败。原始分数保留。

Agent 执行数从 TASK_STARTED 计算，不把跳过 Context 算作执行；Context 使用本地检索，没有模型请求。实际模型请求使用独立 call_id 关联，合成故障和模板审批分开。Mock token 为夹具值，实际 token/费用看 real 行。

计划结构检查验证 DAG、依赖状态、时间顺序、终态和审批绑定；仲裁路由一致性是 Trace 内一致性指标，最终业务正确性另由原 gold 的路由/风险/工单指标衡量。

正式对照同时包含并行、跳过任务和证据仲裁；一次小规模 API 测量的延迟受服务抖动影响。数据和角色 Prompt 相同，不把延迟差归因于单一组件。
